Pflegefassung. Sie behebt zwei Fehler, die beim Testen auf GuideOS aufgefallen
sind – einer davon macht die Installation unübersichtlich.

## Behoben

**Der Fortschritt war während der Installation unsichtbar.**

Beim Start eines Durchlaufs klappt die geteilte Ansicht zusammen, damit das
Protokoll die ganze Breite bekommt. Zugeklappt zeigt sie aber nur eine der
beiden Seiten – und ohne weiteres Zutun war das die Seitenleiste. Nach der
Passwortabfrage sah man deshalb nur die Kategorienliste: kein Fortschritt,
kein Protokoll, keine bedienbaren Knöpfe.

Die Installation lief dabei durch. Man konnte ihr nur nicht zusehen und wusste
nicht, wann sie fertig war.

Dieser Weg war nie geprüft worden: In den bisherigen Tests lief die Ausführung
nie bis zur Anzeige, weil `pkexec` auf eine Passworteingabe wartet – genau die
Stelle, an der ein Mensch sitzt.

**Die Kopfzeile passte bei größerer Schrift nicht in die Seitenleiste.**

„SilentInstaller 1.4.1“ brauchte dort mehr Platz als vorhanden, was eine Flut
von GTK-Warnungen auslöste:

```
Gtk-WARNING: Trying to measure GtkLabel for width of 252,
             but it needs at least 309
```

Die Fassung steht jetzt in der zweiten Zeile, neben dem Namen des Systems. Die
Kopfzeile kommt damit mit 64 statt über 300 Pixeln aus. Im Fenstertitel – also
in der Leiste und beim Umschalten zwischen Fenstern – bleibt sie neben dem
Namen stehen.

## Aktualisieren

```bash
wget https://github.com/Stephan-Lefty/SilentInstaller/releases/download/v1.4.2/silentinstaller_1.4.2_all.deb
sudo apt install ./silentinstaller_1.4.2_all.deb
```

Aus dem Quelltext, etwa unter Arch und Manjaro:

```bash
cd SilentInstaller && git pull && ./install.sh
```

## Wer noch eine blockierte Paketverwaltung hat

Wer von dem in 1.4.1 behobenen Quellen-Widerspruch betroffen ist, muss zuerst
aufräumen – `apt` bricht sonst ab, bevor es zur Installation kommt:

```bash
sudo rm $(grep -rl silentinstaller- /etc/apt/sources.list.d/)
sudo apt update
```

Entfernt werden ausschließlich die von SilentInstaller angelegten Quellen; die
der Distribution bleiben unberührt. Danach lässt sich diese Fassung normal
installieren.
