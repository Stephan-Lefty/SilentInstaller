Diese Fassung beantwortet die Frage, die sich nach dem ersten Release stellte:
Wie erfährt man eigentlich, dass es etwas Neues gibt?

## Neu

- **Hinweis auf neue Fassungen.** Beim Start sieht SilentInstaller höchstens
  einmal am Tag bei GitHub nach und blendet gegebenenfalls ein: „Fassung X ist
  verfügbar“, mit einem Knopf zur Release-Seite.

  Was dabei **nicht** passiert: Es wird nichts heruntergeladen und nichts
  installiert. Gibt es nichts Neues, bleibt es still – keine Einblendung bei
  jedem Start. Ohne Netz oder bei einer unerwarteten Antwort scheitert die
  Abfrage stillschweigend; ein Werkzeug zum Installieren von Programmen soll
  nicht mit Meldungen über sich selbst aufhalten.

  Über *Menü ▸ Auf neue Fassung prüfen* lässt sich jederzeit von Hand
  nachsehen. Dann kommt auch eine Rückmeldung, wenn schon alles aktuell ist.

  Abschaltbar unter *Einstellungen ▸ Installation*, weil dabei eine Verbindung
  zu GitHub aufgebaut wird.

- **Fassung neben dem Namen.** Fenstertitel und Kopfleiste nennen jetzt
  „SilentInstaller 1.3.0“ statt nur den Namen.

## Aktualisieren

```bash
# Debian, Ubuntu und Co.
wget https://github.com/Stephan-Lefty/SilentInstaller/releases/download/v1.3.0/silentinstaller_1.3.0_all.deb
sudo apt install ./silentinstaller_1.3.0_all.deb

# Aus dem Quelltext, etwa unter Arch und Manjaro
cd SilentInstaller && git pull && ./install.sh
```

Eigener Katalog, Profile und Einstellungen bleiben erhalten – sie liegen in
`~/.config/silentinstaller/` und werden nicht angefasst.

## Noch offen

Die polkit-Passwortabfrage auf einem Debian-Desktop ist weiterhin ungeprüft;
im Container lief das Skript als root.
