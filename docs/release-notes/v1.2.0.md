Lieblingsprogramme nach einer Grundinstallation in einem Rutsch nachrüsten –
für Debian- und Arch-basierte Systeme, mit GTK4-Oberfläche.

## Installation

**Debian, Ubuntu, Linux Mint …**

```bash
wget https://github.com/Stephan-Lefty/SilentInstaller/releases/download/v1.2.0/silentinstaller_1.2.0_all.deb
sudo apt install ./silentinstaller_1.2.0_all.deb
```

**Arch, Manjaro, EndeavourOS … oder ohne Paket**

```bash
git clone https://github.com/Stephan-Lefty/SilentInstaller.git
cd SilentInstaller
./silentinstaller.sh
```

Der Starter rüstet fehlende GTK4-Abhängigkeiten selbst nach.

## Was drin ist

- **84 Programme in 11 Kategorien.** Jeder Eintrag kennt seine Paketnamen für
  APT, Pacman und Flathub; die passende Quelle wird auf dem laufenden System
  automatisch gewählt.
- **Vier Quellenarten:** Distributionspakete, Flatpak von Flathub, direkte
  `.deb`-Downloads und Fremd-Repositorys mit eigenem Signaturschlüssel
  (`signed-by`, kein globaler Schlüsselbund).
- **Ein Skript pro Durchlauf.** Aus der Auswahl entsteht ein einziges
  Shell-Skript, das sich vor dem Start ansehen lässt – eine Passwortabfrage
  für alles. Scheitert eine Sammelinstallation, werden die Pakete einzeln
  nachgereicht.
- **Auswahl mitnehmen.** Einmal zusammenstellen, als Datei sichern, auf dem
  nächsten Rechner laden – gleich ob dort Debian oder Arch läuft. Selbst
  angelegte Programme wandern vollständig mit.
- **Profile** als einzelne Dateien; beim ersten Start entsteht automatisch
  eines mit allem, was schon auf dem Rechner liegt.
- **Deutsch und Englisch**, aus der Systemsprache erkannt, zur Laufzeit
  umschaltbar. Hell, dunkel oder wie der Desktop.
- **Eigener Katalog-Editor** – Programme hinzufügen, ändern, ausblenden, ohne
  Texteditor.

## Auf Debian 13 geprüft

Am 18.08.2026 in einem Debian-13-Container durchgespielt – alle Schritte mit
Rückgabe 0:

| Geprüft | Ergebnis |
| --- | --- |
| Paket samt Abhängigkeiten installieren | erfolgreich |
| Systemerkennung | Debian GNU/Linux 13, Familie `debian`, Verwalter `apt` |
| `contrib`, `non-free`, `non-free-firmware` freischalten | in den deb822-Quellen gesetzt |
| Fremdquellen VS Code, Signal, Brave, Vivaldi | alle vier samt Signaturschlüssel eingerichtet |
| `apt-get update` danach | fehlerfrei |
| Probeinstallation aus einer Fremdquelle | Visual Studio Code installiert |
| Oberfläche starten | 84 Einträge, alle mit gültiger Quelle |

**Was noch offen ist:** Im Container läuft das Skript als root, `pkexec` kommt
also nicht zum Zug. Die Passwortabfrage auf einem Debian-Desktop mit polkit ist
weiterhin ungeprüft. Über „Skript anzeigen“ lässt sich vorab genau ansehen, was
ausgeführt würde.
