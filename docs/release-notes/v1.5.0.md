Erstmals wurde jeder Paketname im Katalog gegen die echten Paketquellen von
Arch, Debian 13 und Ubuntu 24.04 geprüft – und gegen Flathub. Dabei kamen fünf
Einträge ans Licht, die so nicht mehr funktioniert hätten.

## Behoben

| Eintrag | Befund |
| --- | --- |
| `p7zip` | Unter Arch durch `7zip` ersetzt (`Replaces: p7zip`) – der alte Name existiert nicht mehr. |
| `virtualbox-host-modules-arch` | Verschwunden. An seine Stelle tritt `virtualbox-host-dkms`, das mit jedem Kernel arbeitet. |
| `telegram-desktop` | Fehlt sowohl in Debian 13 als auch in Ubuntu 24.04. Die APT-Quelle ist entfallen; es bleiben Snap, Flatpak und das Arch-Paket. |
| VirtualBox | Aus Debian entfernt. Unter Ubuntu (multiverse) und Arch bleibt es; für Debian wird der Eintrag ehrlich als nicht verfügbar geführt. |
| VeraCrypt | Von Flathub verschwunden. Unter Arch gibt es das Paket weiterhin – für Debian und Ubuntu wäre der Eintrag ins Leere gelaufen. |

Der letzte Fall war der unangenehmste: VeraCrypt hatte **nur** eine
Flatpak-Quelle. Der Eintrag hätte auf keinem System mehr funktioniert, ohne
dass es jemandem aufgefallen wäre.

## Neu

- **Cryptomator** übernimmt, wo VeraCrypt nicht zu haben ist: verschlüsselte
  Ordner, auch für Cloud-Speicher, über Flathub auf allen drei Systemen.

- **Die Paketnamen werden künftig selbsttätig geprüft.** Ein eigener
  Arbeitsablauf schlägt in Containern von Arch, Debian 13 und Ubuntu 24.04
  nach, ob jeder Name noch existiert, fragt Flathub nach jeder Kennung und
  meldet, wenn Ubuntu bei einem Paket heimlich einen Snap unterschiebt. Er
  läuft montags und bei jeder Änderung am Katalog – auf einem
  Rolling-Release-System wandern Pakete häufiger, als einem lieb ist.

- Die Tests führen die verbliebenen Lücken je System namentlich und begründet
  auf, statt nur eine Höchstzahl zu dulden. Kommt eine neue hinzu oder
  schließt sich eine, schlägt der Test an.

## Stand nach der Korrektur

Gemessen auf GitHubs Rechnern, in echten Containern:

```
Arch Linux     103 von 103 Paketen vorhanden
Debian 13       92 von  92
Ubuntu 24.04    88 von  88, keine stille Umleitung auf Snap
Flathub         49 von  49
```

Was bleibt, sind fünf begründete Lücken: VirtualBox und VeraCrypt unter
Debian, VeraCrypt und fastfetch unter Ubuntu, Synaptic und das
Flatpak-Modul für GNOME Software unter Arch. Alle fünf sind geprüft, im
Katalog vermerkt und werden in der Oberfläche als „nicht verfügbar“ angezeigt,
statt bei der Installation zu scheitern.

## Installation

```bash
wget https://github.com/Stephan-Lefty/SilentInstaller/releases/download/v1.5.0/silentinstaller_1.5.0_all.deb
sudo apt install ./silentinstaller_1.5.0_all.deb
```

Aus dem Quelltext, etwa unter Arch und Manjaro:

```bash
cd SilentInstaller && git pull && ./install.sh
```

## Noch offen

Die Passwortabfrage über polkit lässt sich in Containern nicht prüfen – dort
läuft alles als root, `pkexec` kommt nie zum Zug. Das bleibt dem Test an einem
echten Arbeitsplatzrechner vorbehalten.
