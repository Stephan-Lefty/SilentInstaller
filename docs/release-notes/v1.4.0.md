Diese Fassung geht auf eine Frage aus der Community zurück: Läuft es unter
Ubuntu sauber, wenn Snap bei den Quellen und der Erkennung fehlt – und leitet
apt dort nicht ohnehin um?

Beides stimmte. Eine Prüfung in Ubuntu 24.04 LTS förderte drei Probleme zutage.

## Was nicht stimmte

**Snap kam im Code nicht vor** – weder als Quelle noch bei der Erkennung. Ein
per Snap installiertes Programm galt als nicht installiert. Unter Ubuntu betraf
das den vorinstallierten Firefox.

**Die apt-Umleitung gibt es wirklich.** Die Versionsnummern verraten sie:

| Paket | Kandidat unter Ubuntu 24.04 | hängt von snapd ab |
| --- | --- | --- |
| `firefox` | `1:1snap1-0ubuntu5` | ja |
| `chromium-browser` | `2:1snap1-0ubuntu2` | ja |
| `thunderbird` | `2:1snap1-0ubuntu3` | ja |

Bei Thunderbird stimmte der Paketname sogar – der Benutzer hätte einen Snap
bekommen, während SilentInstaller „APT“ anzeigte.

**Sieben Paketnamen waren für Ubuntu falsch:** `firefox-esr`, `chromium`,
`telegram-desktop`, `fastfetch` und die drei `firmware-*`-Pakete. Das hätte
Snap allein nicht behoben.

## Neu

- **Snap als fünfte Quellenart** – installieren, entfernen, erkennen,
  einschließlich `--classic` für Pakete wie `code` und `blender`. Namen und
  Confinement wurden gegen die Snap-Store-API geprüft.

  Snap gilt nur auf Ubuntu und Abkömmlingen automatisch als verfügbar. Auf
  Debian oder Arch nur, wenn `snap` bereits vorhanden ist – ungefragt einen
  zweiten Paketdienst samt Hintergrunddienst nachzurüsten wäre übergriffig.

- **Distributionsabhängige Paketnamen** über das neue Feld `je_distro`. Die
  speziellste Übereinstimmung gewinnt, sodass **Linux Mint und Pop!_OS die
  Angaben für Ubuntu automatisch erben**. Eine leere Paketliste schaltet eine
  Quelle für ein System ab – so weicht Ubuntu bei Firefox von APT auf Snap aus.

## Vorher und nachher

| System | vorher | nachher |
| --- | --- | --- |
| Debian 13 | 84 aufgelöst | 84 |
| **Ubuntu 24.04** | **7 kaputt + 1 stille Umleitung** | **83, keine Umleitung** |
| Linux Mint | erbte die Fehler | 83 |
| Manjaro | 82 | 82 |

Gegenprobe im Ubuntu-Container: Von 89 genutzten APT-Paketen fehlt keines mehr
außer den vieren aus Fremdquellen, die vorher eingerichtet werden. Stille
Snap-Umleitungen: keine.

`fastfetch` bleibt unter Ubuntu 24.04 „nicht verfügbar“ – es gibt es dort weder
als Paket noch im Snap Store. Das ehrlich anzuzeigen ist besser, als es zu
verschweigen.

## Installation

```bash
wget https://github.com/Stephan-Lefty/SilentInstaller/releases/download/v1.4.0/silentinstaller_1.4.0_all.deb
sudo apt install ./silentinstaller_1.4.0_all.deb
```

Aus dem Quelltext, etwa unter Arch und Manjaro:

```bash
git clone https://github.com/Stephan-Lefty/SilentInstaller.git
cd SilentInstaller && ./install.sh
```

## Noch offen

Die polkit-Passwortabfrage auf einem Desktop ist weiterhin ungeprüft; in den
Containern lief das Skript als root. Die Snap-Installation selbst wurde
ebenfalls nicht real durchgeführt – Snap braucht systemd und läuft in einem
Container nicht. Geprüft sind Paketnamen, Confinement, Auflösung und die
erzeugten Befehle.
